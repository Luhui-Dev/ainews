OpenAI 用智能体流水线发现并修复 948 个 Linux 内核提权漏洞

OpenAI 公布一套自动执行漏洞发现、利用验证和补丁生成的智能体流水线，单次运行确认并修复了 948 个 Linux 内核本地提权漏洞，总 API 成本约 120 万美元。团队称其中至少 10 种利用技术此前未被其研究人员和受访专家掌握，并正与 Linux 维护者及 Patch the Planet 合作披露，显示网络安全智能体已能把研究成果推进到可审阅补丁。

Google 2026-11-06

Google 发布 Gemini Omni 1.2 Flash 视频生成与编辑模型

Google 推出 Gemini Omni 1.2 Flash，可通过 Gemini API 生成 3 至 15 秒视频，并支持多轮对话编辑、参考图一致性、多说话人语音与口型同步，720p 价格为每秒 0.07 美元。相比上一代降低 30% 的价格并覆盖草稿、编辑和 4K 放大流程，使开发者更容易把可控视频生产接入应用，但快速动作和复杂物理仍是官方列出的限制。

字节跳动 Axion 2026-11-05

字节跳动开放 Axion 1.0-35B 的权重、数据与训练流程

字节跳动发布 Apache 2.0 许可的 Axion 1.0-35B 智能体模型，采用约 350 亿总参数、30 亿激活参数的 MoE 架构，并同步开放代码、训练数据、提示词和可复现训练方案。完整披露两阶段 SFT 与长程工具轨迹强化学习流程，使这次发布的价值不仅在模型性能，也在于为智能体后训练和可验证工具使用提供可复用基线。

Anthropic 2026-11-04

Anthropic 开源可验证推理系统 FlashProve

Anthropic 开源 FlashProve，可让服务商在不公开模型权重的情况下，用零知识证明确认回答确实来自指定模型；其在 400B MoE 的 Llama 4 Maverick 上实现约 110 token/s，每 1024 token 产生约 19MB 证明。当前证明成本仍是普通推理的 70 至 95 倍，但该系统为模型防调包、第三方评测核验和生成内容溯源提供了可执行的密码学路径。

GitHub 2026-11-07

GitHub 新 Git 存储系统承载 5000 个并发智能体

GitHub 公布面向智能体规模设计的新 Git 存储系统，在 5000 个并发智能体压力下达到每秒 7200 次推送。代码智能体把提交频率从人类节奏提升到机器并发后，版本控制的写入吞吐、冲突处理和存储架构正在成为开发平台的新基础设施约束。

月之暗面 Kimi 2026-11-05

月之暗面开放 Kimi K3.1 Pro 权重

月之暗面开放 Kimi K3.1 Pro 权重，该模型总参数约 2.8 万亿、激活参数 1040 亿，支持图文输入和 100 万 token 上下文，并强化代码、金融研究与长程智能体任务。旗舰模型从 API 服务转为可下载权重，让企业和研究团队能够直接评估其超长上下文、稀疏注意力与私有部署成本。

腾讯混元 2026-11-04

腾讯混元发布 Hy4，加入视觉输入与电脑操作能力

腾讯混元发布 Hy4 正式版，在扩大预训练与后训练规模的同时加入视觉输入和电脑操作，并针对 Unity、Unreal、Godot 与 Office 文件任务进行训练。模型把长文理解、深度研究和界面执行放进同一开放模型体系，为游戏开发、办公自动化和长程智能体提供了新的国产底座选择。

美团 LongCat 2026-11-02

美团 LongCat 发布 1.6 万亿参数原生多模态模型 LongCat-2.5

美团 LongCat 发布 LongCat-2.5，模型总参数 1.6 万亿、每 token 激活约 480 亿，以统一图文输入支持原生视觉理解、复杂代码库开发和完整项目构建。长序列训练、大规模 Agentic RL 与失败轨迹复现被用于提升长程任务能力，反映出国内超大 MoE 模型正在把多模态感知直接并入智能体训练。

腾讯混元 2026-11-03

腾讯混元推出支持数周研发项目的科研智能体 Hyra 2.0

腾讯混元发布 Hyra 2.0，以 Overall、Mission、Worker 三层协作框架拆解任务，并让智能体在数周级研发项目中生成可供后续研究复用的工具。系统已用于蛋白质设计、分子模拟、数学证明和量子纠错，重点从一次性回答转向能沉淀资产的科研工作流。

vLLM 2026-11-04

vLLM 0.33.0 在 GB300 上将解码性能提升 1.5 至 2 倍

vLLM 发布 0.33.0，合入 927 次提交，升级到 PyTorch 2.14，并提供基于 CUDA 13 的安装包，在 GB300 上实现 1.5 至 2 倍解码性能提升。推理框架对新一代硬件的快速适配可直接降低高吞吐服务成本，但 CUDA 版本要求也会影响现有部署环境的升级节奏。
