DeepSeek 上线 DeepSeek-V4-Flash API 公测

DeepSeek 于 2026 年 8 月 1 日启动 DeepSeek-V4-Flash API 公测，表示其 Agent 能力已超过 V4-Pro-Preview，并支持 Responses API 格式及 Codex 适配。它值得关注，因为高性价比模型开始直接对接开发者工作流和代理框架，模型竞争正在从参数规模转向真实执行效率与接入成本。

月之暗面 Kimi 2026-07-28

月之暗面开源 Kimi K3 权重、技术报告与 Infra 组件

月之暗面发布 Kimi K3 开源模型包，包含 2.8 万亿参数 MoE 权重、技术报告，以及 MoonEP、FlashKDA 和 AgentEnv 等关键基础设施。它值得关注，因为国内团队开始把前沿模型、训练通信和分布式 Agent 环境一起开放，开源生态获取完整技术栈的门槛正在下降。

OpenAI 2026-07-31

OpenAI 下调 GPT-5.6 Luna 与 Terra 价格并推出 Sol Fast

OpenAI 将 GPT-5.6 Luna 价格下调 80%、Terra 下调 20%，同时新增更低延迟的 Sol Fast 版本，并把 ChatGPT app 与 Codex CLI 的自动审查能力迁移到 Luna。它值得关注，因为前沿闭源模型正在主动重写价格性能曲线，Agent 工作流的默认成本结构可能因此发生变化。

Anthropic 2026-07-29

Anthropic 发布开放权重模型立场说明

Anthropic 发布官方文章，表示不支持对开放权重模型实行一刀切禁令，并主张对足够强的开源或闭源模型进行发布前安全评估，同时限制先进芯片和工业级蒸馏能力扩散。它值得关注，因为前沿模型公司的政策表态正在直接影响开源模型、算力管制和安全评测的监管边界。

MiniMax 稀宇科技 2026-07-31

MiniMax 发布通用全模态生成模型 H3

MiniMax 发布 H3，支持文本、图像、视频与声音的统一理解和生成，可输出 15 秒 2K 原生双声道音视频内容。它值得关注，因为全模态生成正从单项能力比拼转向统一生产引擎，这会直接影响广告、电商和互动内容工具的产品形态。

Google DeepMind 2026-07-31

Google DeepMind 发布 Gemini Robotics 2 与 ER 2

Google DeepMind 发布 Gemini Robotics 2，并配套推出高层具身推理模型 ER 2，展示了全身控制、多机器人协作和长步骤任务恢复能力。它值得关注，因为机器人系统正在把多模态推理、规划和动作执行整合成统一栈，具身智能的可部署性正在明显提升。

腾讯混元 2026-07-30

腾讯混元开源投机解码框架 AngelSpec

腾讯混元开源 AngelSpec，并同步开放 drafter 训练、架构设计、线上部署链路，以及 Hy3-A21B 的 MTP 与 DFly drafter 权重和训练代码。它值得关注，因为推理加速已经成为模型落地成本的核心变量，开源可复用的投机解码框架会直接影响服务吞吐与单位算力产出。

字节跳动 Seed 2026-07-31

字节跳动 Seed 团队发布 Seedance 2.5

字节跳动 Seed 团队发布 Seedance 2.5，把单次视频生成时长从 15 秒提升到 30 秒，并支持多轮延长、最多 30 张图片、10 段视频和 10 段音频作为参考。它值得关注，因为视频生成产品正在进入更长时长和更强可控编辑阶段，商业内容制作的自动化密度会继续提升。

Thinking Machines 2026-07-31

Thinking Machines 发布开源多模态模型 Inkling-Small

Thinking Machines 发布 Inkling-Small，这是一款 276B 总参数、12B 激活参数的原生多模态 MoE 开放权重模型，并声称以更小激活规模接近原版 Inkling 的能力。它值得关注，因为开源多模态模型正在把有效激活参数和部署成本做成新的竞争维度，推理栈适配速度会越来越关键。

Anthropic 2026-07-29

Anthropic 更新 MCP 协议并加入无状态模式等能力

Anthropic 通过 ClaudeDevs 账号发布 MCP 协议重大更新，加入 stateless MCP、正式扩展机制、认证加固和弃用策略。它值得关注，因为 Agent 工具协议正在从试验性接口走向工程化标准，兼容性、授权和长期维护会成为生态扩张的前提。

Perplexity 推出 Projects，把原有 Spaces 扩展为支持文件共享和持久记忆 Brain 的长期工作空间。它值得关注，因为消费级 AI 产品正在把记忆、文件和多人协作捆绑成持续运行界面，Agent 产品的竞争点正从单轮回答转向长期工作容器。

腾讯 2026-07-31

腾讯 WorkBuddy 联合腾讯文档上线人机双写功能

腾讯 WorkBuddy 5.3.5 联合腾讯文档上线人机双写，支持用户与 AI 在同一文档中实时协同编辑，并兼容 Word、Excel、PPT、Markdown 及本地 Office 文件。它值得关注，因为办公 Agent 正在从旁路生成进入原生文档编辑链路，AI 协同写作会更快变成高频企业场景。
