Google 2026-09-03

Google 发布面向网络安全任务的 Gemini 3.8 Flash Cyber，并公布 86.2% CyberGym、47.2% CWE-Bench 补丁修复成绩，以及内部漏洞发现基准超过 70% 的成功率。专用网络安全模型开始在接近 Flash 级速度和价格的条件下提供漏洞发现与修复能力，为安全 Agent 的自动化部署提供了新的模型层选择。

Epoch AI 2026-09-04

Epoch AI 报告 Astra 在 FrontierMath Erdős 中解出 2 道此前未被模型解决的问题

Epoch AI 报告 Astra 在 FrontierMath Erdős 上取得 3% 得分，68 道题中有 2 道通过 Lean 验证，而此前参与评测的模型没有解决其中任何一道。该结果为 Astra 在开放数学问题上的能力提供了独立于发布方宣传的增量证据，也显示形式化验证正在成为衡量前沿数学推理的重要手段。

DeepSeek 2026-09-01

DeepSeek 开源 DeepSeek-V4-Flash-Vision-Exp 多模态模型权重

DeepSeek 开源 DeepSeek-V4-Flash-Vision-Exp 权重并采用 MIT 协议，模型在 V4-Flash 文本能力基础上加入图片理解、OCR、图表分析和视觉 Agent 能力。开放权重意味着开发者可以围绕视觉工具调用和多模态 Agent 进行私有部署与二次开发，降低对闭源视觉模型 API 的依赖。

ByteDance Seed 2026-09-03

ByteDance Seed 提出 HarnessDev，用下游反馈评测和改进 Agent Harness

ByteDance Seed 的 HarnessDev 要求模型从一个可运行但较弱的初始 Harness 出发构建执行系统，再利用下游反馈继续改进，并同时评估任务能力与执行 Token 成本；实验覆盖 6 个模型、4 个领域和 2207 个下游样本。结果显示自动生成 Harness 在写作和机器学习实验中已能达到或超过人工系统，但在代码、搜索和研究任务上仍有明显差距，为 Harness Engineering 提供了更系统的评测框架。

vLLM 2026-09-02

vLLM-Omni 与 FastVideo 演示快于播放速度的同步视频音频生成

vLLM-Omni 与 FastVideo 的 FastH3 演示将一段 10.1 秒的同步视频和音频在 8.7 秒内生成完成，实现生成速度快于实际播放速度。多模态生成进入实时速度区间后，交互式视频 Agent、实时内容生成和持续世界模拟开始具备更可行的基础设施条件。

腾讯混元 2026-09-02

腾讯混元将 Hy4 Preview 权重从约 1.5 TB 压缩至约 214 GB

腾讯混元使用 Sherry 稀疏三值量化和混合精度逐层量化，将 Hy4 Preview 权重从约 1.5 TB 压缩至约 214 GB，并称长文理解、多轮检索和编码任务表现接近 BF16 原版。对超大 MoE 模型而言，权重体积下降到原来的约七分之一，会直接降低部署所需显存、存储和节点规模。

SGLang 推进 Miles RL 训练框架，以 SGLang 作为 Rollout 推理引擎

SGLang 团队介绍 Miles RL 训练框架，使用 SGLang 承担 Rollout 推理，并将其定位为更标准化的强化学习后训练基础设施。随着 Rollout、推理服务和训练调度逐渐产品化，模型团队可以减少自建 RL 基础设施的工作量，后训练栈也开始出现类似推理服务层的标准化趋势。
