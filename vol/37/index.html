OpenAI 公布自研推理芯片 Jalapeño 的基准结果

OpenAI 公布 Jalapeño 的推理基准，称其在测试模型负载中峰值吞吐下的单位功耗工作量为 NVIDIA GB200/GB300 的 1.5 至 1.9 倍，并计划在年内部署到自有基础设施。前沿实验室开始直接优化芯片、内核与模型的协同，推理成本和交互延迟会成为模型服务竞争中更核心的变量。

Z.ai 2026-08-27

智谱以 MIT 许可证开放 GLM-5.3-Flash 权重

Z.ai 开放 GLM-5.3-Flash 权重，模型为 320B 总参数、18B 激活参数，支持 100 万 token 上下文和多模态输入。大规模 Agent 模型以宽松许可证进入本地部署与二次开发链路，会让模型能力、量化方案和推理服务之间的组合更快分化。

腾讯混元 2026-08-29

腾讯混元发布 770B 参数模型 Hy4 Preview

腾讯混元发布 Hy4 Preview，总参数 770B、激活参数 49B，支持 100 万 token 上下文，并披露端到端推理吞吐较前代提升 31.8%。大容量 MoE 模型继续把代码、研究和办公等长程任务作为主战场，部署侧的吞吐效率将直接影响其可用成本。

阿里通义 2026-08-29

阿里通义发布多模态 MoE 模型 Qwen3.8-Flash

阿里通义发布 Qwen3.8-Flash，总参数 125B、每 token 激活 6B，支持 100 万 token 上下文和多模态输入。低激活参数与长上下文的组合为编码和办公 Agent 提供了新的成本档位，模型选型将更依赖具体工作负载而非单一排行榜。

Google 2026-08-28

Google 发布视频生成与编辑模型 Gemini Omni 1.1 Flash

Google 发布 Gemini Omni 1.1 Flash，支持将视频延长至 40 秒、首尾帧控制、3 秒参考视频、360p 草稿与 4K 输出。视频模型开始把时间控制、参考条件和分档生成做成明确能力，产品团队可以更系统地平衡预览速度、成本和成片质量。

vLLM 2026-08-29

vLLM 发布投机解码方法的性能对比

vLLM 发布投机解码对比，测试 MTP、EAGLE-3、DFlash、DSpark 等方法在 Gemma、Qwen、Kimi 和 MiniMax 模型及 AMD MI300X/MI355X 上的表现。结果显示不存在通用最优方案，推理团队需要按模型、负载和投机深度调参，而不能把投机解码当作一次性开关。

Nous Research 2026-08-28

Nous Research 让 Hermes Agent 使用受管 Chrome 登录状态浏览网页

Nous Research 为 Hermes Agent 增加以用户身份浏览网页的能力，Agent 可在受管副本中使用 Chrome 配置和登录状态。认证摩擦降低会扩大浏览器 Agent 的可执行范围，也要求产品在权限范围、敏感操作确认和审计记录上提供更细粒度的控制。

阿里云 2026-08-24

阿里上线视频生成模型 Wan3.0

阿里上线 Wan3.0，单次可生成最长 30 秒视频，并支持文档、表格、演示文稿、PDF 和 Markdown 等文件输入。视频生成开始接收工作资料而非仅限提示词或图片，内容制作工具可更直接地接入营销、短剧和企业演示流程。

OpenAI 公布自研推理芯片 Jalapeño 的基准结果

OpenAI 公布 Jalapeño 的推理基准，称其在测试模型负载中峰值吞吐下的单位功耗工作量为 NVIDIA GB200/GB300 的 1.5 至 1.9 倍，并计划在年内部署到自有基础设施。前沿实验室开始直接优化芯片、内核与模型的协同，推理成本和交互延迟会成为模型服务竞争中更核心的变量。

01

智谱以 MIT 许可证开放 GLM-5.3-Flash 权重

Z.ai 开放 GLM-5.3-Flash 权重，模型为 320B 总参数、18B 激活参数，支持 100 万 token 上下文和多模态输入。大规模 Agent 模型以宽松许可证进入本地部署与二次开发链路，会让模型能力、量化方案和推理服务之间的组合更快分化。

02

腾讯混元发布 770B 参数模型 Hy4 Preview

腾讯混元发布 Hy4 Preview，总参数 770B、激活参数 49B，支持 100 万 token 上下文，并披露端到端推理吞吐较前代提升 31.8%。大容量 MoE 模型继续把代码、研究和办公等长程任务作为主战场，部署侧的吞吐效率将直接影响其可用成本。

03

阿里通义发布多模态 MoE 模型 Qwen3.8-Flash

阿里通义发布 Qwen3.8-Flash，总参数 125B、每 token 激活 6B，支持 100 万 token 上下文和多模态输入。低激活参数与长上下文的组合为编码和办公 Agent 提供了新的成本档位，模型选型将更依赖具体工作负载而非单一排行榜。

04

Google 发布视频生成与编辑模型 Gemini Omni 1.1 Flash

Google 发布 Gemini Omni 1.1 Flash，支持将视频延长至 40 秒、首尾帧控制、3 秒参考视频、360p 草稿与 4K 输出。视频模型开始把时间控制、参考条件和分档生成做成明确能力，产品团队可以更系统地平衡预览速度、成本和成片质量。

05

vLLM 发布投机解码方法的性能对比

vLLM 发布投机解码对比，测试 MTP、EAGLE-3、DFlash、DSpark 等方法在 Gemma、Qwen、Kimi 和 MiniMax 模型及 AMD MI300X/MI355X 上的表现。结果显示不存在通用最优方案，推理团队需要按模型、负载和投机深度调参，而不能把投机解码当作一次性开关。

06

Nous Research 让 Hermes Agent 使用受管 Chrome 登录状态浏览网页

Nous Research 为 Hermes Agent 增加以用户身份浏览网页的能力，Agent 可在受管副本中使用 Chrome 配置和登录状态。认证摩擦降低会扩大浏览器 Agent 的可执行范围，也要求产品在权限范围、敏感操作确认和审计记录上提供更细粒度的控制。

07

阿里上线视频生成模型 Wan3.0

阿里上线 Wan3.0，单次可生成最长 30 秒视频，并支持文档、表格、演示文稿、PDF 和 Markdown 等文件输入。视频生成开始接收工作资料而非仅限提示词或图片，内容制作工具可更直接地接入营销、短剧和企业演示流程。

08

字节跳动推出办公 Agent 产品豆包工作

字节跳动推出豆包工作，支持拆解任务、调用工具、操作虚拟桌面，以及完成文档、PPT、网页和系统搭建等任务。它与飞书的企业上下文打通，显示办公 Agent 的落地重点正在从对话能力转向跨工具执行和组织数据连接。

09

阿里千问办公国际版 QwenWork 开启公测

千问办公国际版 QwenWork 开启公测，提供网页与 PC 客户端，已接入 Slack、Notion 等海外协作工具。办公 Agent 出海不只取决于模型语言能力，也取决于与海外身份体系、协作软件和企业数据源的连接深度。
