OpenAI 发布 GPT-6.1 Sol

OpenAI 发布 GPT-6.1 Sol，API 输入和输出价格分别为每百万 token 2 美元和 10 美元，缓存输入降至 0.10 美元，官方将其定位为接近 Astra 智能水平、价格约为后者五分之一的主力模型。更低的调用成本与高缓存折扣，将直接改善长时 Agent、代码工作流和大规模模型路由的单位经济性。

OpenAI 推出常驻型 Agent 产品 Dots

OpenAI 推出 Dots，每个 Dot 运行在独立云电脑上，可连接 4,000 多款应用及 Slack、Teams，并允许用户分别设置自主执行、需审批和禁止执行的边界。产品面向 Pro、Business Premium 和 Enterprise 用户开放，把跨应用上下文、长期任务跟踪与 Codex 任务编排整合为常驻工作流。

Google 2026-10-01

Google 发布 Gemini 4 Argon

Google 发布面向编程、企业知识工作和网络防御的 Gemini 4 Argon，官方称其在 19 项公开基准中的 13 项取得领先，并率先向政府用户和受信任的网络防御机构开放。有限预览与后续扩大访问的安排显示，高网络能力模型正把能力发布与分级安全准入绑定得更紧。

机器之心 2026-09-29

Anthropic 发布 Claude Sonnet 5.5

Anthropic 发布 Claude Sonnet 5.5，官方数据称其运行速度提升 30% 以上，Terminal-Bench 4.0 得分由上一代的 10.3% 提升至 70.6%，定价约为 Opus 5.5 的一半。性能与价格向旗舰靠拢，使 Sonnet 更适合成为编程 Agent 和日常知识工作的默认模型。

DeepSeek 2026-09-30

DeepSeek 开源面向华为昇腾的基础设施组件

DeepSeek 开源面向华为昇腾平台的 TileLang、DeepGEMM、DeepEP 和 FlashMLA 等组件，覆盖编译、矩阵运算、分布式通信与稀疏注意力。与英伟达平台组件形成对应的开放栈，为模型训练和推理迁移到昇腾提供了更完整的底层工具链。

Black Forest Labs 2026-10-02

Black Forest Labs 发布 FLUX 3 Image

Black Forest Labs 发布 FLUX 3 Image，支持最高 4K 原生生成、最多 10 张参考图、边界框布局控制和定向多轮编辑，商业权重已开放，开放权重版本计划随后推出。生成、布局和局部编辑合并到同一模型后，设计工具可以减少多模型串联及重复重绘的成本。

可灵AI 2026-09-29

快手发布视频生成模型 Kling 4.0

快手发布 Kling 4.0，轻量版 Flash 已向部分会员开放预览，支持单次生成最长 30 秒原生视频、多关键帧控制、多模态参考与精准视频编辑，并计划提供 4K HDR 输出和最长 2 分钟续拍。更长时长与可编辑控制同时进入生成链路，有助于视频模型从短片段演示转向可用于生产的叙事工作流。

Meta AI 2026-10-01

Meta 提出可编辑上下文的 Context Language Models

Meta 研究团队提出 Context Language Models，将上下文视为可编辑文件，并把上下文管理策略学习进模型权重，而不是依赖外部 Harness 维护追加式对话记录。研究报告称该方法在 24 小时多仓库 Agent 协作任务中以相同计算量取得 65% 的性能提升，为长时任务的上下文管理提供了模型内路径。

Meta AI 2026-10-03

Meta 公布 Muse Spark 参与完成的六篇数学论文

Meta 公布六篇使用 Muse Spark 1.1 和 1.2 研究开放数学问题的论文，研究者直接通过 meta.ai 对话完成工作，没有定制 Agent 脚手架，并标注人类与 AI 各自主要撰写的段落。论文还由另一组数学家复核，为评估通用聊天模型参与真实科研提供了比单一基准更透明的过程材料。

DeepSeek 2026-10-03

DeepSeek Harness 发布桌面版本

DeepSeek Harness 发布 macOS 和 Windows 桌面版本，Linux 用户可通过 npm 安装，用户能在本地工作区直接运行 Agent，并扩展团队、终端、子 Agent 与网页搜索等插件。桌面入口降低了命令行门槛，同时保留可组合 Harness 的结构，便于开发者调整工具链和执行策略。

Reka AI 2026-10-03

Reka AI 开源逆动力学模型 RIDM

Reka AI 以 Apache 2.0 许可发布逆动力学模型 RIDM，模型在游戏数据上训练，可迁移到真实视频并从画面中提取电机和相机动作。开放的动作反推模型为视频数据自动标注、机器人模仿学习和世界模型训练提供了新的数据接口。

OpenAI 发布 GPT-6.1 Sol

OpenAI 发布 GPT-6.1 Sol，API 输入和输出价格分别为每百万 token 2 美元和 10 美元，缓存输入降至 0.10 美元，官方将其定位为接近 Astra 智能水平、价格约为后者五分之一的主力模型。更低的调用成本与高缓存折扣，将直接改善长时 Agent、代码工作流和大规模模型路由的单位经济性。

01

OpenAI 推出常驻型 Agent 产品 Dots

OpenAI 推出 Dots，每个 Dot 运行在独立云电脑上，可连接 4,000 多款应用及 Slack、Teams，并允许用户分别设置自主执行、需审批和禁止执行的边界。产品面向 Pro、Business Premium 和 Enterprise 用户开放，把跨应用上下文、长期任务跟踪与 Codex 任务编排整合为常驻工作流。

02

Google 发布 Gemini 4 Argon

Google 发布面向编程、企业知识工作和网络防御的 Gemini 4 Argon，官方称其在 19 项公开基准中的 13 项取得领先，并率先向政府用户和受信任的网络防御机构开放。有限预览与后续扩大访问的安排显示，高网络能力模型正把能力发布与分级安全准入绑定得更紧。

03

Anthropic 发布 Claude Sonnet 5.5

Anthropic 发布 Claude Sonnet 5.5，官方数据称其运行速度提升 30% 以上，Terminal-Bench 4.0 得分由上一代的 10.3% 提升至 70.6%，定价约为 Opus 5.5 的一半。性能与价格向旗舰靠拢，使 Sonnet 更适合成为编程 Agent 和日常知识工作的默认模型。

04

DeepSeek 开源面向华为昇腾的基础设施组件

DeepSeek 开源面向华为昇腾平台的 TileLang、DeepGEMM、DeepEP 和 FlashMLA 等组件，覆盖编译、矩阵运算、分布式通信与稀疏注意力。与英伟达平台组件形成对应的开放栈，为模型训练和推理迁移到昇腾提供了更完整的底层工具链。

05

Black Forest Labs 发布 FLUX 3 Image

Black Forest Labs 发布 FLUX 3 Image，支持最高 4K 原生生成、最多 10 张参考图、边界框布局控制和定向多轮编辑，商业权重已开放，开放权重版本计划随后推出。生成、布局和局部编辑合并到同一模型后，设计工具可以减少多模型串联及重复重绘的成本。

06

快手发布视频生成模型 Kling 4.0

快手发布 Kling 4.0，轻量版 Flash 已向部分会员开放预览，支持单次生成最长 30 秒原生视频、多关键帧控制、多模态参考与精准视频编辑，并计划提供 4K HDR 输出和最长 2 分钟续拍。更长时长与可编辑控制同时进入生成链路，有助于视频模型从短片段演示转向可用于生产的叙事工作流。

07

Meta 提出可编辑上下文的 Context Language Models

Meta 研究团队提出 Context Language Models，将上下文视为可编辑文件，并把上下文管理策略学习进模型权重，而不是依赖外部 Harness 维护追加式对话记录。研究报告称该方法在 24 小时多仓库 Agent 协作任务中以相同计算量取得 65% 的性能提升，为长时任务的上下文管理提供了模型内路径。

08

Meta 公布 Muse Spark 参与完成的六篇数学论文

Meta 公布六篇使用 Muse Spark 1.1 和 1.2 研究开放数学问题的论文，研究者直接通过 meta.ai 对话完成工作，没有定制 Agent 脚手架，并标注人类与 AI 各自主要撰写的段落。论文还由另一组数学家复核，为评估通用聊天模型参与真实科研提供了比单一基准更透明的过程材料。

09

DeepSeek Harness 发布桌面版本

DeepSeek Harness 发布 macOS 和 Windows 桌面版本，Linux 用户可通过 npm 安装，用户能在本地工作区直接运行 Agent，并扩展团队、终端、子 Agent 与网页搜索等插件。桌面入口降低了命令行门槛，同时保留可组合 Harness 的结构，便于开发者调整工具链和执行策略。

10

Reka AI 开源逆动力学模型 RIDM

Reka AI 以 Apache 2.0 许可发布逆动力学模型 RIDM，模型在游戏数据上训练，可迁移到真实视频并从画面中提取电机和相机动作。开放的动作反推模型为视频数据自动标注、机器人模仿学习和世界模型训练提供了新的数据接口。
