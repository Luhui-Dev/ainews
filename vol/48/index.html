Google 2026-11-11

Google 发布面向长程智能体任务的 Gemini 4 Carbon

Google 发布 Gemini 4 Carbon，将其定位为软件工程、网络安全、知识工作和科学研究中最复杂长程任务的旗舰模型，并通过 Gemini API、AI Studio、Android Studio 与多家编程智能体平台开放。Google 仍建议多数编码和知识任务使用 Argon，Carbon 的产品分层显示前沿模型正按任务难度、成本与执行时长形成更明确的调用策略。

Google DeepMind 2026-11-13

Google 推出 Gemini 4 Hydrogen，提供 100 万 token 上下文

Google DeepMind 推出强调速度的 Gemini 4 Hydrogen，称其任务完成速度是 Gemini 3.8 Flash 的 2.5 倍，支持 100 万 token 上下文，输入与输出价格分别为每百万 token 1.5 美元和 7.5 美元。模型覆盖免费 API 层并成为 Search AI Mode 默认模型，为需要低延迟长上下文的智能体和搜索应用增加了新的性能成本选项。

Google DeepMind 2026-11-12

Google DeepMind 用 Gemini 智能体为 Signal 生成 600 万行形式化证明

Google DeepMind 的 AlphaProof Code 框架为未经修改的 libsignal 生成从源码到编译机器码的 Lean 安全证明，Gemini 智能体产出超过 600 万行证明，并在重新引入两个旧漏洞后证明对应版本不安全。五人团队用四周完成关键验证、人工集中审查约 1% 内容，展示了智能体压缩高成本软件形式化验证周期的潜力。

Google 2026-11-12

Google 发布面向封闭选项判断的 Gemini Decisions API

Google 推出由 Gemini Decision 1 驱动的 Decisions API，可一次处理最多 1000 个问题和 255 个选项，接受文本、图像、音频、视频及 PDF，并为每个答案返回置信度。其 256K 上下文与 150 至 250 毫秒端到端延迟，使分类、审核和规则评分可以绕过逐 token 文本生成，形成更适合批量决策的模型接口。

DeepSeek 2026-11-14

DeepSeek 将搜索、文件、OCR、语音识别和语音合成开放为 API

DeepSeek 把应用中的搜索、文件处理、OCR、ASR 和 TTS 能力开放为 API，并为不同工具单独计费，同时发布开源前端。开发者可直接组合模型与多模态工具，而无需复刻消费端应用能力，这会降低构建研究、文档和语音智能体的接入成本。

vLLM 2026-11-12

vLLM 拆分编码、预填充与解码阶段，P90 首 token 延迟降低最多 47%

vLLM 升级编码、预填充和解码分离架构，在 DeepSeek V4.1 Flash、并发 64 至 128 的测试中将 P90 首 token 延迟降低 44% 至 47%，每 GPU 吞吐提升 6.6% 至 9.5%。Mooncake/NIXL 嵌入传输与跨编码器缓存把多模态服务的不同计算阶段解耦，为高并发部署提供了更细粒度的资源调度方式。

字节跳动 Seed 2026-11-10

字节跳动 Seed 发布支持连续编辑 100 轮的 Seedream 5.5

字节跳动 Seed 发布图像创作模型 Seedream 5.5，强调连续 100 轮编辑中的非编辑区域像素级保持，并加入原生 RGBA 透明素材生成，官方称严重文字崩坏率降至 0.4%。稳定多轮编辑与透明通道输出把模型能力从单次生成推进到可持续修改的设计工作流，减少反复抠图和重做素材的成本。

ggml 2026-11-14

ggml 发布 1.0 并清理 llama.cpp 公共接口中的 35 个弃用函数

ggml 发布 1.0 稳定版，并从 llama.cpp 公共头文件中移除 35 个已弃用函数，标志核心接口进入稳定阶段。作为本地模型推理生态的底层依赖，稳定 API 有助于下游运行时、桌面应用和硬件后端降低升级与兼容维护成本。

黄仁勋辞任英伟达 CEO，Colette Kress 出任临时 CEO

英伟达董事会于 11 月 11 日接受黄仁勋辞任 CEO 的决定，并由现任 CFO Colette Kress 兼任临时 CEO，Harvey Jones 出任董事会首任独立主席。此次管理层更替发生在董事会启动独立调查之后，后续治理安排与战略连续性将直接影响全球 AI 芯片供应链。

01

Google 发布面向长程智能体任务的 Gemini 4 Carbon

Google 发布 Gemini 4 Carbon，将其定位为软件工程、网络安全、知识工作和科学研究中最复杂长程任务的旗舰模型，并通过 Gemini API、AI Studio、Android Studio 与多家编程智能体平台开放。Google 仍建议多数编码和知识任务使用 Argon，Carbon 的产品分层显示前沿模型正按任务难度、成本与执行时长形成更明确的调用策略。

02

Google 推出 Gemini 4 Hydrogen，提供 100 万 token 上下文

Google DeepMind 推出强调速度的 Gemini 4 Hydrogen，称其任务完成速度是 Gemini 3.8 Flash 的 2.5 倍，支持 100 万 token 上下文，输入与输出价格分别为每百万 token 1.5 美元和 7.5 美元。模型覆盖免费 API 层并成为 Search AI Mode 默认模型，为需要低延迟长上下文的智能体和搜索应用增加了新的性能成本选项。

03

Google DeepMind 用 Gemini 智能体为 Signal 生成 600 万行形式化证明

Google DeepMind 的 AlphaProof Code 框架为未经修改的 libsignal 生成从源码到编译机器码的 Lean 安全证明，Gemini 智能体产出超过 600 万行证明，并在重新引入两个旧漏洞后证明对应版本不安全。五人团队用四周完成关键验证、人工集中审查约 1% 内容，展示了智能体压缩高成本软件形式化验证周期的潜力。

04

Google 发布面向封闭选项判断的 Gemini Decisions API

Google 推出由 Gemini Decision 1 驱动的 Decisions API，可一次处理最多 1000 个问题和 255 个选项，接受文本、图像、音频、视频及 PDF，并为每个答案返回置信度。其 256K 上下文与 150 至 250 毫秒端到端延迟，使分类、审核和规则评分可以绕过逐 token 文本生成，形成更适合批量决策的模型接口。

05

DeepSeek 将搜索、文件、OCR、语音识别和语音合成开放为 API

DeepSeek 把应用中的搜索、文件处理、OCR、ASR 和 TTS 能力开放为 API，并为不同工具单独计费，同时发布开源前端。开发者可直接组合模型与多模态工具，而无需复刻消费端应用能力，这会降低构建研究、文档和语音智能体的接入成本。

06

vLLM 拆分编码、预填充与解码阶段，P90 首 token 延迟降低最多 47%

vLLM 升级编码、预填充和解码分离架构，在 DeepSeek V4.1 Flash、并发 64 至 128 的测试中将 P90 首 token 延迟降低 44% 至 47%，每 GPU 吞吐提升 6.6% 至 9.5%。Mooncake/NIXL 嵌入传输与跨编码器缓存把多模态服务的不同计算阶段解耦，为高并发部署提供了更细粒度的资源调度方式。

07

字节跳动 Seed 发布支持连续编辑 100 轮的 Seedream 5.5

字节跳动 Seed 发布图像创作模型 Seedream 5.5，强调连续 100 轮编辑中的非编辑区域像素级保持，并加入原生 RGBA 透明素材生成，官方称严重文字崩坏率降至 0.4%。稳定多轮编辑与透明通道输出把模型能力从单次生成推进到可持续修改的设计工作流，减少反复抠图和重做素材的成本。

08

ggml 发布 1.0 并清理 llama.cpp 公共接口中的 35 个弃用函数

ggml 发布 1.0 稳定版，并从 llama.cpp 公共头文件中移除 35 个已弃用函数，标志核心接口进入稳定阶段。作为本地模型推理生态的底层依赖，稳定 API 有助于下游运行时、桌面应用和硬件后端降低升级与兼容维护成本。
